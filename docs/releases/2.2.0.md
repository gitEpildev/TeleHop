# TeleHop 2.2.0

Released to the GalaxyRealms Network on 19 October 2026. Reconciled into this standalone repository on 4 November 2026. This publication does not restart or update live servers.

## Changes from 2.1.0

- Centred green title countdown, updated once per second.
- No repeated countdown numbers in chat or the action bar.
- Existing `show-countdown` option controls the title. Completion and movement cancellation clear it.
- Translations for all six bundled languages and three countdown regression tests.
- Paper and Velocity version metadata updated consistently to 2.2.0.

Redis TLS, destination ping estimates, RTP selection guards and cooldown fixes from 2.1.0 are retained. Shared messaging and database code are unchanged. There is no database migration or protocol change in this release.

## Recorded deployment

The 19 October deployment record identifies all four production Paper backends, both Velocity proxies and Development USA on 2.2.0. It records preserved data/configurations and 95 passing tests. A subsequent production-only configuration correction set RTP delays to five seconds and added the missing countdown message to existing English files. The owner confirmed the Java countdown worked.

This is historical deployment evidence, not a fresh live-server audit on 4 November. Bedrock visual acceptance and the broader client-version matrix remain outstanding.

## Upgrade requirements

Back up the existing JARs and configuration. Install matching Paper and Velocity builds, restarting instances individually and keeping one proxy available. Preserve homes, warps and all database records.

Add `countdown-title` to existing language files, including English. The loader falls back to on-disk English, not to a fresh bundled copy. It does not merge missing bundled keys automatically. See [message upgrade instructions](../messages.md).

A zero-second delay or a delay-bypass permission still skips warmup. The plugin update does not impose the network's five-second configuration on other installations.

## Verification

The original release passed 95 tests and build/style checks. An instrumented Paper scheduler harness checked titles 5 through 1, no countdown chat/action-bar messages, completion, movement cancellation and disabled countdowns. These checks do not establish rendered Bedrock behaviour.

On 4 November 2026, a fresh `mvn clean verify` passed across all seven modules, with 95 tests, zero failures/errors/skips and Checkstyle passing. Markdown links and the no-em-dash documentation check also passed. Runtime source and resource files are compared with the recorded server-local 2.2.0 source. No new gameplay changes are introduced by this reconciliation.

## Rollback

Stop one affected instance and restore its previous JAR. Preserve the live data folder and database; this countdown-only release does not require a database restore. Retain the added language key unless intentionally undoing the message configuration. Verify recovery before advancing to another instance.
