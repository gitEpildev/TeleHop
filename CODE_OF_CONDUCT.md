# TeleHop code of conduct

Players, server owners and contributors are welcome in the issue tracker, pull requests and support Discord. When you disagree about a change, explain what you observed and give the other person room to respond.

- Keep feedback about the plugin or the proposed change. Help people who are new to running a Minecraft network.
- Respect people's boundaries. Harassment, threats, discriminatory remarks and repeated unwanted contact have no place here.
- Ask before sharing anyone's private messages, player information or server logs.

If you experience or witness a problem, ask `@Epildev` for a private conversation in the support server. Share the relevant message link privately if you have it. A maintainer may ask someone to edit a comment, remove content or restrict participation. [TeleHop support Discord](https://discord.gg/E8kpxdGbxn)
