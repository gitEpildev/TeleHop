# Reporting a TeleHop security issue

If you think someone can bypass a permission, act as another player or access private server data through TeleHop, contact `@Epildev` through the support Discord. In the public channel, ask for a private conversation and wait for the maintainer to reply before sharing details. [TeleHop support Discord](https://discord.gg/E8kpxdGbxn)

In private, include the TeleHop version, backend software and Minecraft version. If a proxy was involved, include its software version and whether the players used the same proxy. Describe the access the player had, what happened and what you expected. Remove credentials, forwarding secrets and identifying player details from any excerpts.

For ordinary bugs, installation questions and feature requests, use the public issue tracker or support Discord. [Troubleshooting](docs/troubleshooting.md) · [TeleHop issues](https://github.com/gitEpildev/TeleHop/issues)
